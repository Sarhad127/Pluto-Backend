Pluto Java Backend

Spring Boot backend for the Pluto productivity application. Handles authentication, board management, scheduling, notes, calendar data, and real-time collaboration.

Features

- User authentication with JWT and OAuth
- CRUD for boards, tasks, notes, and calendar events
- Real-time collaboration via WebSockets
- Weekly schedule system with validation
- Secure profile management
- MySQL data persistence

Tech Stack

- Java 17
- Spring Boot
- Spring Security with JWT
- Spring WebSockets
- Spring Data JPA
- MySQL (Aiven)
- Docker with CI/CD
- Maven
